Internal transactional character wallet mutations for gold, zeni and dragon_coin. BigInt amounts and numeric(40,0) persistence. Row lock serializes changes, ledger operation ID prevents duplicate credit/debit; conflicting reuse rejected. Replay returns current balance, not historical balance. Caller must authorize and commit/rollback the transaction. No HTTP route or battle reward integration. Legacy Zeni account/character ownership semantics and transfers need audit before purchases are enabled. Currency allowlist is provisional, not yet editable content.
