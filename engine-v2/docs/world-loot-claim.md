# World loot claim and sale

The internal claim operation locks character then battle, requires a finished battle, grants pinned-revision items, and clears pending loot in the same transaction. Selected pending-loot group indices may be sold only when the pinned item definition has a positive integer sell price and is not marked unsellable; the turtle stone is explicitly excluded. A repeat returns the original receipt without duplicating items or gold. Full inventory rolls back the entire claim and sale, retaining pending loot for retry. This deliberately avoids the legacy partial-grant duplication risk. Existing catalog entries without explicit sell metadata are denied sale; migration of authoritative legacy sell metadata, integration tests, ownership authorization and HTTP wiring remain pending. Gold earned during combat is already credited by settlement, not credited again here.
