Pure shared hit resolver ports legacy story-combat order: dodge, armor penetration and technique armor, average damage, intelligence reduction, racial modifiers, technique resistance, critical, critical resistance, guard. Caller supplies RNG; tests use deterministic samples. No browser or database dependency. Explicitly clamp fractional reductions to [0,1] and reject nonfinite values; this is a defensive behavior for malformed inputs, not a rebalance of valid legacy values. No live combat wiring, no rewards or turn engine yet. Existing legacy code remains untouched.
