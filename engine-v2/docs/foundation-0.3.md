# Foundation 0.3
Initial PostgreSQL schema, not a complete game database. From engine-v2, set local .env password, run docker compose up -d --wait, then sh tools/migrate.sh twice. Run docker compose exec -T postgres psql -X -v ON_ERROR_STOP=1 -U dboidle -d dboidle < test/schema.sql.
Migration is transactional and serialized. Do not edit applied migration; extend runner with subsequent numbered migrations. No legacy data imported.
Stable content IDs are separated from player instances; references to definitions must be validated by application and publication logic. JSON fields are transitional typed-contract extension points, not arbitrary executable content. Numeric values require exact decimal handling in application, never JS Number for large balances. Slot limits, race IDs, stat rules, stack limits and quality IDs are not finalized; compare legacy rules before enforcing. Wallet ledger and balance must be updated atomically by future application services; schema alone does not guarantee consistency. Roles and sessions require real auth, token hashing and expiration enforcement. Training uniqueness is provisional pending legacy audit. No public API connection yet. No production deployment.
