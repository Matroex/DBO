# Boss catalog

Two built-in bosses imported from js/world.js, with exact stats and base rewards. Guardian special parameters are catalog data only, not an implemented real-time simulation. Daily victory ledger is internal and must be invoked in the same transaction as finalizing a boss victory; it is not yet wired to gameplay. The legacy browser-local day is replaced in the server configuration by Europe/Warsaw as a provisional shared reset zone. The limit is per character and boss. Failed attempts do not consume a slot.
