# Development authentication API
Set DATABASE_URL privately, start PostgreSQL and apply migrations, npm install, npm run build, npm start. Loopback only. POST /api/v1/auth/register and /login with JSON login/password; GET /auth/me and POST /auth/logout use Authorization: Bearer token. Paths have /api/v1 prefix. GET /api/v1/ready checks database and migration 003. Do not store tokens in localStorage or expose this development API publicly. Before production: TLS, secure browser session transport, distributed rate limiting, account recovery, expiration cleanup, abuse testing, dependency lockfile and security review. IP limiter is local to process; no proxy trust. Existing health endpoint remains scaffold metadata. No frontend changes.
